Release rule:
The final distributable package must be generated from a clean Git tree.

The final package manifest is generated by tools/package_release.ps1.

The generated release manifest records:
- release version
- exact Git HEAD
- branch
- creation timestamp
- packaged artifact sizes
- SHA256 hashes
- publication metadata and metadata hashes
- exact reproducible snapshot

The generated package also contains SHA256SUMS.txt.

This tracked contract is not itself the final dynamic release manifest.
The final dynamic manifest lives inside the generated release package.

Historical April/May publication manifests and releases remain historical artifacts and must not be interpreted as the current release.
