## 6. Conditional covariance calculation

Consider an additional,
explicitly hypothetical model.

Let E be a set of marks.

Let G be an abelian group.

Let u:E -> G be a map.

For any chosen reference o
in E, define:

L_o(e) = u(e)-u(o).

For a second reference o'
in E, one has:

L_o'(e)
= u(e)-u(o')
= L_o(e)-L_o(o').

Consequently:

L_o'(e_j)-L_o'(e_i)
= u(e_j)-u(e_i)

and:

L_o(e_j)-L_o(e_i)
= u(e_j)-u(e_i).

Therefore:

L_o'(e_j)-L_o'(e_i)
= L_o(e_j)-L_o(e_i).

This is an elementary
conditional calculation.

It establishes that
reference differences cancel
under the declared
group-valued representation.

It is not a MADELEINE
theorem already established
by the frozen DMO-001 demo.

The required structure
has been added explicitly
for this comparison.

## 7. Counterexample for distances

A different interpretation
of d gives a different result.

Consider ordinary real-line
distance:

d(o,e)=|e-o|.

Take marks:

A=1;
B=2;
C=3.

Choose original reference:

o=0.

Then:

L_o(A)=1;
L_o(B)=2;
L_o(C)=3.

The original DMO-001
numerical values are matched.

The derived difference is:

L_o(C)-L_o(A)=2.

Now choose:

o'=2.

Then:

L_o'(A)=1;
L_o'(B)=0;
L_o'(C)=1.

Thus:

L_o'(C)-L_o'(A)=0.

The difference changed
from 2 to 0.

This elementary counterexample
shows that an arbitrary
distance-based reading
does not necessarily preserve
differences under
a change of reference.

It does not refute DMO-001:
that demo does not claim
the stronger invariance.

It shows why an additional
formal condition is necessary
before claiming covariance.

## 9. Relabeling versus origin change

Value-preserving relabeling:

changes the names of marks
while retaining the
same reading assignments.

Origin change:

selects another reference
and recalculates readings
under a defined relation.

The first operation
was tested in DMO-001.

The second was not.

The two must not be treated
as the same transformation.
