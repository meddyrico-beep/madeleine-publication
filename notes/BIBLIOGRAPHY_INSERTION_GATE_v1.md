# 2. Texto candidato para Tomo III

Como referencia externa de terminología, se adopta la noción estándar de cadena de Markov en tiempo discreto. En LAB-FEN-001, los sustitutos Markov-1 se emplean como referencia nula operacional en métricas del protocolo, incluida la evaluación del exceso de dependencia histórica. Esta función debe distinguirse de la definición de \(k^\ast\) en HISTORY-DEPTH-v1: \(k^\ast\) es una clasificación instrumental bajo el protocolo congelado y no se identifica aquí con un orden Markoviano universal.

# 4. Exclusiones explícitas

La inserción no autoriza:

- identificar k* con un orden Markoviano matemático universal;
- afirmar que LAB-D2 sea un sistema físico Markoviano o no Markoviano;
- atribuir HISTORY-DEPTH a Norris;
- atribuir el núcleo MADELEINE a teoría de cadenas de Markov;
- presentar la referencia externa como validación de los resultados LAB.
